AlignFix

A Tool for Analysis and Refinement of Parallel Corpora

Overview

AlignFix is a sophisticated browser-based application for processing parallel text corpora, computing word alignments, and extracting high-quality phrase pairs for machine translation and linguistic research.

Built entirely with WebAssembly (WASM) and running 100% in your browser, AlignFix provides desktop-class performance without requiring any server infrastructure or data uploads. Your data stays completely private and secure on your local machine.

Key Philosophy: Privacy-first, offline-capable, and blazingly fast through WebAssembly compilation.

Key Features

Word Alignment

  • FastAlign implementation compiled to WASM
  • Bidirectional alignment (forward + reverse)
  • Symmetrization strategies (intersection, union, grow-diag)
  • Quality scoring with agreement, stability, and asymmetry metrics
  • Interactive visualization of alignment points

Quality Analysis

  • Comprehensive alignment quality metrics
  • Interactive histograms and distributions
  • Filtering by confidence, agreement, and coverage
  • Export quality reports to CSV
  • Real-time statistics and visualizations

Phrase Extraction

  • Parallel phrase pair extraction from aligned corpora
  • Multi-threaded processing using Web Workers
  • Configurable phrase length (1-7 words)
  • Frequency filtering and quality thresholds
  • Batch processing for large corpora (1M+ sentences)

Project Management

  • SQLite database stored in browser (IndexedDB)
  • Multiple project support with isolation
  • Persistent storage across sessions
  • Import/export projects and phrase tables
  • Efficient memory management for large datasets

Technology Stack

Frontend

  • Vanilla JavaScript - No framework overhead
  • Bootstrap 5 - Modern, responsive UI
  • Chart.js - Interactive data visualization
  • Font Awesome - Rich icon library

Backend (WASM)

  • WebAssembly - Near-native performance

Performance Optimizations

  • Multi-threading - Web Workers for parallel processing

  • Memory profiling - Track peak usage and optimize allocation

How It Works

  1. 1. Import Your Corpus

    Upload parallel text files (source and target languages) in plain text format, one sentence per line.

  2. 2. Compute Alignments

    Run FastAlign to compute bidirectional word alignments. The algorithm uses expectation-maximization (EM) to learn translation probabilities.

  3. 3. Analyze Quality

    Review alignment quality metrics including confidence scores, agreement rates, and coverage statistics. Filter low-quality alignments and identify problematic sentence pairs.

  4. 4. Extract Phrases

    Extract phrase pairs using heuristic methods based on alignment consistency. Configure phrase length, frequency thresholds, and quality filters.

  5. 5. Fix Errors & Refine

    Identify and fix alignment errors, remove misaligned sentence pairs, correct phrase boundaries, and refine the corpus quality through iterative analysis and manual review.

  6. 6. Export Results

    Export cleaned phrase tables, refined alignments, and quality reports in standard formats (CSV, TMX, Moses).

Use Cases

Machine Translation

Build phrase tables for statistical and neural machine translation systems. Extract high-quality parallel phrases for training MT models.

Education & Training

Teach translation concepts, demonstrate alignment algorithms, and provide hands-on experience with parallel corpus processing.

Linguistic Research

Analyze translation patterns, study cross-lingual phenomena, and research alignment algorithms for low-resource language pairs.

Data Quality Assessment

Evaluate parallel corpus quality, identify misalignments, and clean noisy data before training translation systems.
